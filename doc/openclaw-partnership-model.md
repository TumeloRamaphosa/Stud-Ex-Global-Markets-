## 1. WHAT IS OPENCLAW?

**OpenClaw** is an open-source autonomous coding agent framework. Think of it as the "operating system" for AI software agents:

- Agents can read files, write code, run shell commands, use Git
- Multi-model support: Ollama (local), Claude (cloud), GPT-4 (cloud)
- Tool-use architecture: agents can call APIs, query databases, send messages
- Event-driven: agents react to triggers (new email, payment received, error alert)
- Extensible: custom tools and agents can be added via plugins

**How it compares:**

| Tool | Type | Best For | Limitation |
|------|------|----------|------------|
| **OpenClaw** | Open-source agent framework | Custom agent orchestration | Requires setup |
| **Claude Code** | Proprietary CLI agent | Interactive coding sessions | Single-agent, Anthropic only |
| **Cursor** | AI-native IDE | Developer productivity | IDE-bound |
| **Continue.dev** | IDE extension | Multi-model coding | IDE-bound |
| **ProjectGoose** | Agent framework | Enterprise integration | Early stage |

**Naledi's Advantage:** We wrap OpenClaw in enterprise-grade GCP infrastructure and sell it as a managed service.

## 2. PARTNERSHIP TIERS

### Tier 1 — Reseller

**Who:** Marketing agencies, IT consultancies, business coaches, freelancers

**What they get:**
- Commission: **20%** of every project they refer
- Co-branded landing page (auto-generated)
- Partner portal to track referrals and earnings
- Basic training module (1 hour, AI-guided)

**What they do:**

- Handle initial relationship (optional)
- Naledi handles all delivery

**Example:** A marketing agency in Cape Town refers 5 clients/month at R20k average. They earn R20k/month commission.

### Tier 2 — White-Label Partner

**Who:** Established agencies that want to offer "AI development" under their own brand

**What they get:**
- Commission: **30%** of project revenue
- Platform fee: **R5,000/month** for white-label access
- Full white-label: their logo, their domain, their email
- API access to quote engine, build pipeline, and delivery system
- Partner dashboard with client management
- Co-marketing: case studies, social posts, blog content (auto-generated)

**What they do:**
- Sell under their brand
- Set their own prices (can markup 50–100%)
- Handle first-line support
- Naledi handles all delivery and technical work

**Example:** An agency white-labels Naledi, marks up 50%, sells at R30k. Naledi builds for R20k. Agency keeps R10k + 30% of R20k = R16k total per project.

### Tier 3 — Enterprise Partner

**Who:** Large companies (banks, telecoms, retailers, government) that want to deploy OpenClaw internally

**What they get:**
- Custom OpenClaw deployment on their GCP project
- Private instance of Naledi agents
- Dedicated support (AI + human hybrid)
- Custom agent development
- Training for their team
- SLA: 99.9% uptime, 4-hour response time

**Pricing:**
- Setup: **R150,000–R500,000** (custom integration)
- Monthly: **R25,000–R100,000** (platform + support)
- Per-project: **R15,000–R50,000** (agent labor)

**Example:** A South African bank deploys OpenClaw for internal tool development. R300k setup + R50k/month.

### Tier 4 — Technology Partner

**Who:** Software companies that want to integrate Naledi agents into their products

**What they get:**
- API access to all Naledi agents
- SDKs: Python, TypeScript, Go
- Revenue share: **15%** of revenue from Naledi-powered features
- Co-marketing and joint press releases
- Early access to new agent features

**Example:** A POS software company integrates Naledi Brain to offer AI-powered inventory forecasting to their 5,000 restaurant clients.
